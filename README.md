# Harvest Shore

Unity 2021.3.45f2 で制作した 2D 農業ゲームです。作物の栽培、アイテム管理、ショップ、NPC 会話、マップ移動を実装しています。

## 主な機能

- 耕す・種をまく・水をやる・収穫する農業サイクル
- インベントリ、ショートカットバー、収納箱
- 商品・数量・所持金を確認する売買処理
- NPC との会話とショップの表示
- 時間・日付、セーブ／ロード、シーン切り替え
- ScriptableObject によるアイテム・作物・会話等のデータ管理

## 開発環境

- Unity 2021.3.45f2 / C#
- Universal Render Pipeline 12.1 系
- TextMesh Pro、Cinemachine、DOTween
- 対応ビルド: Windows 64 bit

## プロジェクトを開く

1. 本リポジトリを取得し、Unity Hub から Unity 2021.3.45f2 で開きます。
2. `THIRD_PARTY.md` に記載した外部素材を、元のフォルダー構成で導入します。
3. `Assets/Scenes/StartGame.unity` を開いて再生します。
4. Windows 向けビルドでは、Build Settings に登録済みの 6 シーンを使用します。

公開リポジトリにはプログラム、シーン、Prefab、設定データを収録しています。市販素材を再配布しないため、`Assets/M Studio` は含まれません。これらの素材を導入するまでは、画像・音声・アニメーション等の参照と一部の補助スクリプトが不足します。

## 操作

| 操作 | 入力 |
|---|---|
| 移動 | WASD / 矢印キー |
| ゆっくり歩く | 左 Shift |
| バッグの開閉 | B |
| ショートカット選択 | 数字キー 0〜9 |
| 選択した道具・アイテムを使う | 左クリック |
| 収納箱を開く | 近くで右クリック |
| NPC と話す・会話を進める | Space |
| ショップ・収納箱を閉じる | Esc |

ショップは対応する NPC との会話後に開きます。バッグ内のアイテムはドラッグで移動できます。
